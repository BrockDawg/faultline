# Landing the forklift judge, 31 Oct 2026

This log records how the forklift judge's public drop was merged into this repo, and what was checked.
No model call was made and nothing was spent.

## 1. The copy

The drop held 217 files.
123 of them were already here byte for byte (`cmp`): the eight packs, `LICENSE`, `NOTICE`, `src/faultline/__init__.py` and `src/faultline/adapters/__init__.py`, so no pack changed.
92 files were new and were copied: `demo/`, `src/faultline/adapters/video/`, `tests/adapters/video/`, `scripts/check_spans.py` and `scripts/contract_smoke.py`.
The drop's own `pyproject.toml` and `uv.lock` were not copied.
`pyproject.toml` gained two dependencies (`numpy>=1.26`, `meta-sam-parser>=0.1.0`) and two commands (`faultline-video`, `steward`); everything else in it is as it was.
`uv lock` resolved both from the index (numpy 2.5.4, meta-sam-parser 0.1.0) and kept every existing pin; `uv sync` installed them.

Two more files were needed to make the drop work here: `.gitignore` gained three lines, and one file was added.

- `.gitignore` ignored every `data/` folder, which hid the judge's own data (site values, camera marks, pinned reads) in `src/faultline/adapters/video/data/`.
  One line, `!src/faultline/adapters/video/data/`, lets that folder in; the root `data/` stays ignored.
- The judge keeps its record in `record/` at the repo root, and a replay test writes a blob there, so `/record/` joins the run output `.gitignore` keeps out.
- `tests/adapters/video/__init__.py` makes the video tests a package, as `tests/adapters/` already is, so their `conftest.py` no longer shadows `tests/conftest.py` (without it, six test files failed to import).

## 2. Format and lint

Only the drop's 42 Python files were formatted and linted, with this repo's own ruff settings (line length 100; E, F, I, B, UP); no file that existed before was reformatted.
`ruff format` reformatted 40 of them, and `ruff check --fix` fixed 19 findings (import order, three unused imports, `datetime.UTC`).
742 lines were still over 100 columns.
They were shortened without changing any value the code runs on: long strings split into adjacent literals, a backslash-newline inside long triple-quoted strings (the page templates and prompts), long comments rewrapped, and long docstrings reflowed.
Every runtime string, prompt included, compiles to the same value as before, checked by comparing each file's syntax tree before and after; only docstring whitespace differs.
The rest were fixed by hand, without changing behaviour:

- `zip()` without `strict=`, six places: `strict=False` added, which is what `zip()` already did.
- Two lambdas in `cli.py` that read loop variables: the variables are bound as default arguments; each lambda is called in the same iteration, so the values are the same.
- Three unused loop variables renamed with a leading underscore, and three variables named `l` renamed `left`.
- One `%` format in a test written as an f-string.

`uv run ruff check .` and `uv run ruff format --check .` pass on the whole repo.
